# Security policy

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a security problem.

Report it privately through GitHub: **Security → Report a vulnerability** on this repository. Include what you found, how to reproduce it, and the commit you tested.

You should receive an acknowledgement within a week. Fixes are released on `master`; there are no supported older versions.

## Scope

This repository is a test harness. Its secrets, test credentials and databases are disposable by design. Vulnerabilities in the Theme Manager or Authentication layers themselves belong to those layers, but reporting them here is welcome and they will be passed on.
